1どんな道具か

稽古の予定を組むとき、いちばん面倒なのは 「今日はこの人が来られない。じゃあ何の場面ができる？」 を台本とにらめっこして探すところです。香盤メーカーはそこだけをやります。

誰が来られないか → できる場面が出る → その日の香盤ができる

※ 香盤（こうばん）＝ どの場面を何時からやるかを並べた、その日の進行表のことです。

インターネットにデータは送りません 登録した内容はお使いの端末の中だけに保存されます。 ログインもアカウント登録も要りません。くわしくは7。

2まず、さわってみる

説明を読むより、動いているものを触るほうが早いです。 はじめて開いた画面に サンプルで試す があります。

押すと『ロミオとジュリエット』（役26人・全26場面）がぜんぶ入った状態になり、 すべての画面をそのまま試せます。 自分の劇団のデータを1文字も入れずに、全機能を確認できます。

サンプルを消したくなったら 設定（右上の歯車）→ 一番下のデータ → 全データを消去 で空にできます。そこから自分の台本を入れてください。

3はじめの準備（3つ登録する）

最初の1回だけ、右上の歯車（設定）を開いて3つを登録します。 この順番で入れてください。あとの画面がそのまま使えます。

  1. 役（登場人物）を入れる
    設定 → 役（登場人物）

    稽古に出る役を、役名で登録します。人の名前でも構いません（配役が決まっていないときは役名のままでOK）。

  2. 場面を入れて、出る役をチェックする
    設定 → 場面

    場番号とタイトルを入れて追加すると、その下に役の一覧が出ます。 その場面に出る役をタップして黒くします。 ここが「できる／できない」の判定のもとになるので、ここだけは丁寧に入れてください。

    • 分…その場面の稽古にかける時間。はじめは60分です。香盤を組むときの長さになります。
    • 時代・幕…任意です。時代が行き来する台本で見分けたいときだけ入れてください（例：第一幕）。
  3. 稽古日と時間帯を入れる
    設定 → 稽古日・時間帯

    日付を追加すると、その日に「午後 13:00–17:00」が1つ入った状態でできます。 名前も時刻も変えられますし、＋ 時間帯を追加 で 「午前」「午後」のように1日を分けられます。

    ※ ここで分けた時間帯（コマ）の単位で、出欠と判定が出ます。 午前だけ来られない人がいるなら、午前と午後は分けておくと便利です。

3つとも入ると、設定の上に出ている「登録の順番」の案内は自動で消えます。

4毎回の使い方（出欠 → できる場面）

ここからが毎回やるところです。きょうの稽古 タブを開きます。

① 日付を選ぶ

上に稽古日が並んでいるので、入力したい日を押します。

② 出られない時間帯を、赤く塗る

役ごとのマス目が出ます。出られないところをタップすると赤くなります。 もう一度押すと戻ります。

画面のイメージ
役 午前
10:00–13:00		 午後
14:00–18:00		 終日
ロミオ終日
ジュリエット終日
乳母終日
出られる 出られない（NG） 終日＝その日まるごと切り替え

右端の 終日 は、その人のその日ぜんぶを一度に切り替えるボタンです。 1日まるごと来られない人は、これを1回押すだけで済みます。

③ 下に「できる場面」が出る

塗ったその場で、下の判定が変わります。時間帯ごとに、こう出ます。

画面のイメージ（午後 14:00–18:00）
欠席 ジュリエット
できる場面（2）
3場・広場のけんか 7場・決闘
できない場面（1）
5場・バルコニー （ジュリエットが不在）

できない場面には、誰がいないからできないのかが出ます。 「この人だけ来られれば1本増える」が分かるので、連絡すべき相手がすぐ決まります。

5香盤を組む・印刷する

香盤 タブに切り替えます。日付を選んで進めます。

  1. （任意）締切を入れる

    「◯場を◯時までに終わらせたい」を入れておくと、自動生成がそれを優先します。 早く帰る人がいる場面などに使ってください。無くても組めます。

  2. 自動生成して、3つの案から選ぶ

    香盤を自動生成 を押すと、考え方の違う3案が並びます。

    • 番号順消化…場番号の若い順に、できるものから詰める
    • 欠け役優先…欠けやすい役がそろった枠を優先して使う
    • 消化数最大…短い場面から詰めて、こなす本数を増やす

    各案に 消化（何場やれるか） と 積み残し（できない場面） が出るので、 見比べて この案を採用 を押します。

  3. 手で並べ替える

    採用すると手動編集ができます。場面のブロックをドラッグして順番や枠を入れ替えられます。

    役がそろっていない置き方をすると ⚠ ◯◯が不在 と赤く出ますが、 置くこと自体はできます。「本人不在でも立ち位置だけ確認する」といった 現場の判断を止めないためです。

  4. 印刷して貼り出す

    🖨 印刷用表示 を押すと、その日の香盤だけの表になって印刷できます。 ボタンや設定は印刷されません。 印刷画面で「PDFとして保存」を選べば、そのままLINEやメールでも送れます。

6人に配る

設定 → データ → この内容を配る（URLをコピー）

いま登録されている内容ぜんぶ（役・場面・稽古日・出欠・組んだ香盤）が 1本のURLになります。LINEやメールで送れば、相手はそのURLを開くだけで同じ状態を見られます。 アプリを入れる必要も、ログインも要りません。

⚠ 受け取った人の内容は、置き換わります URLを開くと、その端末に入っていた内容は受け取った内容に置き換わります。 置き換える前に確認画面が出て、いまの内容のまま開く を選べば守れますが、 行き来してやりとりする使い方には向きません。 出欠はまとめ役がひとりで入力し、できあがったものを配るのがいちばん安全です。

7データの保存について

  • 入力した内容はその端末の中に自動で保存されます。保存ボタンはありません。
  • サーバーには送っていません。ほかの人からは見えません。
  • ただし端末ごとに別々です。iPhoneで入れた内容はパソコンには出てきません。
控えを取っておきたいときは 設定 → データ → この内容を配る（URLをコピー） で出たURLを、自分あてにメールやLINEで送っておいてください。 それがそのままバックアップになります。端末を変えたときも、そのURLを開けば元に戻せます。

※ ブラウザの履歴やサイトデータを消す操作をすると、保存された内容も消えることがあります。 大事な香盤は、上のURLか印刷したPDFを残しておくと安心です。

8ホーム画面に置いておく

毎回URLを探すのは大変なので、ホーム画面に置いておくと普通のアプリのように開けます。

iPhone / iPad（Safari）

  1. 香盤メーカーを Safari で開く
  2. 下（または右上）の共有ボタン（□に↑）を押す
  3. メニューを下にたどって 「ホーム画面に追加」 を押す

Android（Chrome）

  1. 香盤メーカーを Chrome で開く
  2. 右上の ⋮ を押す
  3. 「ホーム画面に追加」 を押す
大事なこと ホーム画面のアイコンはそのブラウザに入っているデータを見に行きます。 追加したあとは、いつも同じアイコンから開いてください。 別のブラウザで開くと、中身が空に見えます（消えたわけではありません）。

9こまったとき

場面が「できない」ばかりになる
その場面に必要な役としてチェックを付けすぎていないかを見てください。 実際にはその日に稽古しない役までチェックが付いていると、その場面はできない判定になります。 設定 → 場面 で見直せます。
できる場面が1つも出ない
その時間帯に、多くの役がNGになっている状態です。 判定の「欠席」に出ている人が、その日の鍵になります。
役を消したら、ほかも消えた
役を削除すると、その役の場面チェックと、入れた出欠も一緒に消えます。 残しておくとおかしな判定になるためです。名前を直したいだけなら、削除せず 名前の欄を書き換えてください。
稽古日や時間帯を消したら、出欠はどうなる？
その日（その時間帯）に入れた出欠も一緒に消えます。日程が変わったときは、 消して入れ直すより、日付や時刻を書き換えるほうが入力が残ります。
同じ日付を2回追加できない
同じ日は1つだけです。1日に2部あるときは、日を増やすのではなく その日に時間帯（コマ）を足してください。
数字を入れると画面が拡大してしまう
起きないようにしてあります。もし起きたら、お使いの端末と場所を教えてください。
最初からやり直したい
設定 → データ → 全データを消去。 元には戻せません。消す前に「この内容を配る」のURLを自分あてに送っておくと、 やっぱり戻したいときに復元できます。
